## Cloud-Specific Rules

- Keep AWS SDK usage and infrastructure-facing integrations encapsulated behind dedicated modules instead of scattering them across handlers.
- Preserve clear boundaries between portfolio/blog content generation, orchestration logic, and cloud transport triggers.
- Prefer idempotent Lambda flows with explicit error handling and retry-safe behavior for scheduled or event-driven executions.
- Validate runtime, environment variable, and deployment contract changes against the real entrypoints before modifying handlers or cloud configuration.
- For any visual, editorial, or brand-related output generated by cloud automations, use `D:\Documentos\Workspace\Projects\portfolio` as the visual source of truth, especially for blog aesthetics, tone, metadata presentation, and design tokens.
