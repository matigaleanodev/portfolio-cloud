# Portfolio Cloud v1.3.0

Production publication and quality improvements

- Required subscriber storage in a private bucket distinct from public media, with matching SAM and GitHub Actions configuration.
- Copy-and-verify SHA-256 migration before public cleanup; production data migration completed on October 9.
- Future and invalid publication dates rejected by release processing, notifications and editorial knowledge publication.
- Resend SDK error envelopes propagated instead of treating failed notifications as successful.

## Publication and compatibility

Public routes and contracts remain compatible. Merge commits retain the topic-based history. The annotated tag is published on the integrated commit after deployments are confirmed.

The new runtime requires `R2_BUCKET=portoflio-blog-media` and `SUBSCRIBERS_BUCKET=portfolio-blog-subscribers`; deploy code and SAM together. Migration already completed: do not repeat it or restore public records.
