# Portfolio Cloud v1.3.0

Suscriptores privados y publicación programada

- Almacenamiento obligatorio de suscriptores en un bucket privado distinto del bucket de media; configuración SAM y GitHub Actions alineadas.
- Migración por copia y verificación SHA-256 antes de retirar objetos públicos; ejecución operativa completada el 9 de octubre.
- Rechazo de fechas futuras o inválidas en releases, notificaciones y publicación del conocimiento editorial.
- Propagación de los errores que Resend devuelve sin rechazar la promesa, evitando marcar notificaciones fallidas como exitosas.

## Publicación y compatibilidad

Esta release conserva las rutas y contratos públicos. Las mejoras se integran mediante merge commit para preservar los commits por tema. El tag anotado se publica sobre el commit integrado después de confirmar los despliegues.

El nuevo runtime exige `R2_BUCKET=portoflio-blog-media` y `SUBSCRIBERS_BUCKET=portfolio-blog-subscribers`; desplegar el código y SAM juntos. La migración ya terminó: no repetirla ni restaurar registros públicos.
